# Cross-border Chain of Custody smart contract

Solidity source code of the SPOC-oriented cross-border chain-of-custody contract evaluated in the accompanying manuscript.

- Contract: `contracts/CrossBorderCoCOpt.sol`
- Compiler: Solidity 0.8.34, EVM target Osaka, optimizer disabled
- Deployed runtime bytecode: 24,477 bytes

Evidence files are not submitted to the contract; it records reference hashes, metadata, storage pointers, and custody events.
